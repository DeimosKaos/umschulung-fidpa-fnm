## Schritt 2: Einmaliges Lesen *(IHK-relevanter Text, phänomenologisch aufbereitet)*

### 1. Merkmale & JVM-Architektur (Kersken 7.2.1)
Java kombiniert Kompilierung und Interpretation: Der Compiler **`javac`** übersetzt Quellcode (`.java`) in plattformunabhängigen **Bytecode (`.class`)**, den die **JVM (*Java Virtual Machine*, `java`)** auf jedem OS ausführt (*„Write once, run anywhere“*).
- **JDK vs. JRE:** Das **JRE** (*Runtime Environment*) enthält JVM + Standardklassen zum Ausführen; das **JDK** (*Development Kit*) ergänzt Compiler (`javac`), Debugger & Werkzeuge zum Entwickeln.
- **Konventionen:** Dateiname muss exakt dem Namen der `public class` entsprechen; Einstiegspunkt ist immer `public static void main(String[] args)`. Jede Anweisung endet mit `;`.

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Warum kann dieselbe `.class`-Datei sowohl auf Windows als auch auf Linux laufen, ein kompiliertes C-Programm aber nicht?*

### 2. Datentypen, Strings & Typumwandlung (Kersken 7.2.2)
Java ist **statisch und streng typisiert** (Variablen brauchen vorab einen festen Typ):
- **Primitive Datentypen:** Ganzzahlen `byte` (8 Bit), `short` (16), **`int`** (32), `long` (64); Fließkomma `float`, **`double`**; Zeichen `char` (`'A'`); Wahrheitswert **`boolean`** (`true`/`false`, *keine* Zahlen!).
- **Referenztypen (z. B. `String`):** `String` ist eine Klasse (großgeschrieben, `"Text"`). **IHK-Falle:** `s1 == s2` prüft nur die *Speicherreferenz*! Inhaltlichen Textvergleich macht man immer mit **`s1.equals(s2)`**!
- **Ganzzahl-Division:** `5 / 2` ergibt in Java **`2`** (nicht `2.5`!) – mindestens ein Operand muss `double` sein (`5.0 / 2`).

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Welchen Wert hat `ergebnis` bei `double ergebnis = 7 / 2;` in Java – und warum?*

### 3. Kontrollstrukturen & Arrays (Kersken 7.2.2)
- **Verzweigungen:** `if (...) { ... } else { ... }` und `switch (wert) { case 1: ... break; default: ... }` (ohne `break` tritt *Fall-Through* in den nächsten Case ein!).
- **Schleifen:** `for (int i = 0; i < 10; i++)`, `while (...)`, fußgesteuert `do { ... } while (...);` sowie `for (String s : liste)` (*Enhanced for*).
- **Arrays:** Feste Größe nach Erzeugung (`int[] zahlen = new int[5];`), Index startet bei `0`, Länge über Feld `zahlen.length` (*ohne Klammern!*, bei `String` dagegen `s.length()`).
