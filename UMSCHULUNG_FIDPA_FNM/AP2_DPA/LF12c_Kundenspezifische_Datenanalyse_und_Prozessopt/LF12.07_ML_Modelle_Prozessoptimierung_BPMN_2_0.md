### 1. Das richtige ML-Modell für den Geschäftsprozess wählen *(Kersken 10.3)*

| Prozess-Ziel im Kundenprojekt | Aufgabentyp | Passendes ML-Verfahren |
| :--- | :--- | :--- |
| **Eingangsticket automatisch Abteilung zuweisen** | Klassifikation | Logistische Regression / Decision Tree / MLP |
| **Erwartete Durchlaufzeit / Bedarf vorhersagen** | Regression | Lineare Regression / Random Forest Regressor |
| **Kunden / Fehlerbilder ohne Vorgabe gruppieren** | Clustering *(Unsupervised)* | K-Means-Clustering |
| **Komplexe Bild-/Mustererkennung *(z. B. Ausschuss)*** | Klassifikation | Künstliches Neuronales Netz (`MLPClassifier` / CNN) |

### 2. Integration in BPMN 2.0: Soll-Prozess optimieren *(Kersken 12.2)*

Ein ML-Modell bringt erst dann wirtschaftlichen Nutzen, wenn es nahtlos in den **BPMN-2.0-Prozess** eingebettet wird:
1. **Service Task:** *„Daten über REST-API an ML-Modell senden & Konfidenzscore berechnen“*
2. **XOR-Gateway (`×`) mit Human-in-the-Loop:**
   * **Konfidenz $\ge 90\%$:** Automatische Weiterverarbeitung (*Dunkelverarbeitung / Straight-Through Processing*)
   * **Konfidenz $< 90\%$:** Eskalation an **User Task** (*„Sachbearbeiter prüft manuell“*) → Feedback fließt später ins Retraining!

> [!question] ⏸️ Denkstopp (10 Sek.)
> Warum ist ein **Konfidenz-Gateway (`< 90 %` → Mensch prüft)** in einem automatisierten Rechnungs- oder Betrugsprozess wirtschaftlich und rechtlich oft klüger als 100 % blinde Vollautomatisierung?

## 🔺 Schritt 3: N – Nuklei & Pyramidenschema®

![[../../assets/LF12.07_Pyramide.svg]]

- **Spitze:** ML-Modelle entfalten echten Geschäftswert erst durch gezielte Einbettung in optimierte BPMN-2.0-Sollprozesse mit Human-in-the-Loop.
- **Nukleus 1 (Modellauswahl (10.3)):** Kategorie → Klassifikation (Log. Reg. / Tree / MLP) Zahlenwert → Regression (OLS) Gruppen finden → K-Means Immer mit Baseline starten!
- **Nukleus 2 (BPMN-Integration (12.2)):** Service Task ruft ML-API auf XOR-Gateway prüft Konfidenz Hoch → Dunkelverarbeitung Niedrig → User Task (Mensch) Vorher/Nachher (Ist vs. Soll) dokumentiert den Nutzen!
- **Nukleus 3 (Betrieb & Governance):** Human-in-the-Loop sichert Qualität & EU-AI-Act-Compliance Drift-Monitoring: Modellgüte über Zeit überwachen Regelmäßiges Retraining

> [!tip] 💡 IHK-Prüfungstipp
> Zeige im IHK-Projekt immer **Ist-BPMN vs. Soll-BPMN**: Man sieht auf einen Blick, welche manuellen Schritte wegfallen, wo die ML-Service-Task sitzt und wie Ausnahmen abgefangen werden!
