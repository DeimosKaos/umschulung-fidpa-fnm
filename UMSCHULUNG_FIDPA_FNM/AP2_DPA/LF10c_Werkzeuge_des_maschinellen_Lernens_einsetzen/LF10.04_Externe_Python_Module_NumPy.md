## 📖 Schritt 2: Einmaliges Lesen *(Fokus-Wissen aus Kersken)*

### 1. Externe Python-Module verwalten *(Kersken 9.4.1)*

Standardmäßig liefert Python nur die Standardbibliothek mit. Wissenschaftliche Pakete aus dem **PyPI *(Python Package Index, pypi.org)*** oder der **Anaconda-Distribution** werden per Paketmanager installiert:

| Kommando | Zweck | Hinweis aus Kersken |
| :--- | :--- | :--- |
| `pip3 install numpy` | Installiert ein Modul aus PyPI | Alternativ in Anaconda: `conda install numpy` |
| `pip3 list` | Listet alle installierten Module mit Version auf | `conda search *begriff*` für Stichwortsuche |
| `pip3 show numpy` | Zeigt Details (Version, Speicherort, `Requires`, `Required-by`) | `pip3 search` wurde 2020 deaktiviert → Suche auf `pypi.org` |

**Das SciPy-Ökosystem *(Scientific Python)*:** **NumPy** (Arrays & lineare Algebra), **SciPy** (wissenschaftliche Algorithmen), **Matplotlib** (Diagramme), **IPython** (interaktive Shell), **SymPy** (Computer-Algebra-System) und **pandas** (Tabellenanalyse).

### 2. NumPy-Arrays (`np.array`) & Indexierung *(Kersken 9.4.2)*

Das Kernobjekt ist `numpy.ndarray` (homogene, C-optimierte mehrdimensionale Arrays):

```python
import numpy as np

m1 = np.array([[3, 2, 1], [-1, -2, -3]])  # 2x3-Matrix
zv1 = np.array([-2, 4, -6])                # 1D-Zeilenvektor
sv1 = np.array([[-2], [4], [-6]])          # 2D-Spaltenvektor (3x1)

# Elementzugriff: Standard vs. NumPy-Kommaschreibweise
wert = m1[0, 2]       # Zeile 0, Spalte 2 -> 1 (nur in NumPy!)
nullen = np.zeros([3, 4])  # 3x4-Nullmatrix (analog: np.ones)
```

### 3. Rechnen mit Vektoren & Matrizen in NumPy

| Operation | Python/NumPy-Code | Wichtiges Detail |
| :--- | :--- | :--- |
| **Elementweise Addition / Subtraktion** | `m1 + m2`, `m1 - m2` | Funktioniert direkt ohne Schleife (*Vektorisierung*) |
| **Skalarmultiplikation** | `m1 * 4`, `-3 * sv1` | Multipliziert jedes Element mit dem Skalar |
| **Skalarprodukt *(1D-Vektoren)*** | `np.dot(zv1, zv2)` oder `zv1.dot(zv2)` | Liefert einzelnen Skalarwert (`-40`) |
| **Transponieren** | `m1.transpose()` *(oder `m1.T`)* | Nötig, bevor Spaltenvektoren per `dot` multipliziert werden |
| **Matrixmultiplikation *(Falk)*** | `m3.dot(m4)` oder **`m4 @ m3`** | Der `@`-Operator existiert seit Python 3.5 |

## 🔺 Schritt 3: N – Nuklei & Pyramidenschema®

![[../../assets/LF10.04_Pyramide.svg]]

- **Spitze:** pip/conda binden das SciPy-Ökosystem ein, und NumPy liefert vektorisierte Arrays für schnelle Vektor- und Matrixoperationen.
- **Nukleus 1 (Paketverwaltung & SciPy):** PyPI (pypi.org) + pip3 install pip3 list / pip3 show <modul> Anaconda: conda install / search SciPy-Stack: NumPy, SciPy, Matplotlib, IPython, SymPy, pandas
- **Nukleus 2 (np.array & Indexierung):** Homogenes, schnelles C-Array 1D: np.array([1, 2, 3]) 2D-Matrix: np.array([[...],[...]]) Komma-Index: m1[zeile, spalte] Spezialmatrizen: np.zeros([r,c]) und np.ones([r,c])
- **Nukleus 3 (Vektor- & Matrix-Ops):** + / - / * : elementweise! .dot() / np.dot(): Skalarprodukt @ Operator (seit Python 3.5): echte Matrixmultiplikation! .transpose(): Zeilen ↔ Spalten Keine langsamen Python-Loops

> [!tip] 💡 IHK-Prüfungstipp
> Häufige Python-Falle in Prüfungen: `A * B` multipliziert in NumPy elementweise (Hadamard-Produkt), während `A @ B` (bzw. `A.dot(B)`) die echte Matrixmultiplikation ausführt!
