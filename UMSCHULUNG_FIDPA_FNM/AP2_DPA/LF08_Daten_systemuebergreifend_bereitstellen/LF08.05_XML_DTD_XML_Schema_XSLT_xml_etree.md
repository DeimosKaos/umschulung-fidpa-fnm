## Schritt 2: Einmaliges Lesen *(IHK-relevanter Text, phänomenologisch aufbereitet)*

### 1. XML-Aufbau: Wohlgeformt vs. Valide (Kersken 16.1–16.2)
- **Wohlgeformt (*well-formed*):** Erfüllt alle XML-Syntaxregeln (`16.1.2`): (1) **genau ein Wurzelelement**, (2) korrekte **Verschachtelung** (`<a><b></b></a>`), (3) jedes Tag geschlossen (oder `<leer/>`), (4) Attribute immer in `"..."`, (5) *case-sensitive* Tag-Namen, (6) Sonderzeichen `< > & " '` als Entities (`&lt;`, `&amp;`, ...) oder im **`<![CDATA[ ... ]]>`**-Block. *Nicht wohlgeformtes XML bricht beim Parser sofort ab!*
- **Valide (*valid*):** Ist zusätzlich gegen ein Regelwerk (**DTD** oder **XML Schema / XSD**) geprüft:
  - **DTD (`<!DOCTYPE ...>`):** Älter, keine XML-Syntax, kennt praktisch **keine Datentypen** (nur `#PCDATA` Text).
  - **XML Schema (XSD):** Selbst in XML geschrieben, unterstützt **echte Datentypen** (`xs:integer`, `xs:date`, Wertebereiche) und **Namespaces (`xmlns`)** gegen Namenskollisionen beim Mischen mehrerer XML-Standards.

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Kann ein XML-Dokument **valide** sein, wenn es **nicht wohlgeformt** ist?*

### 2. XSLT & XPath (Kersken 16.3)
**XSLT (*Extensible Stylesheet Language Transformations*)** verwandelt ein XML-Dokument deklarativ in ein anderes Format (HTML-Bericht, anderes XML, Text). Mit **XPath** navigiert man dabei gezielt durch den Baum (z. B. `/comics/comic[@language='en-US']/series`).

### 3. XML-Parser: DOM vs. SAX/StAX vs. `xml.etree` (Kersken 16.4)
| Verfahren | Prinzip | Vorteil | Nachteil / Einsatz |
| :--- | :--- | :--- | :--- |
| **DOM** / `xml.etree` / JDOM | **Baumbasiert:** Lädt gesamten Baum in RAM | Sehr bequem (Index, Iteration, Ändern) | Hoher **RAM-Verbrauch** bei riesigen Dateien! |
| **SAX / StAX** | **Streaming / Ereignisbasiert:** Liest zeichenweise durch | Verarbeitet **GB-große** XML-Dateien mit kaum RAM | Zustand/Tiefe selbst merken; nur vorwärts lesen |
| **Data Binding (JAXB)** | Bildet XML direkt auf Klassen/Objekte ab | Native OOP-Nutzung | Feste Klassengenerierung aus XSD nötig |

- **Python `xml.etree.ElementTree`:** `doc = ElementTree.parse('datei.xml')`, `root = doc.getroot()` (oder `fromstring()`). Zugriff per `elem.tag`, `elem.text` und `elem.attrib` (Dictionary!).
