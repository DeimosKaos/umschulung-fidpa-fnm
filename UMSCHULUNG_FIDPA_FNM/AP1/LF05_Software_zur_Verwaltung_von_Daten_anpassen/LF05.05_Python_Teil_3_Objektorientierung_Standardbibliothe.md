## Schritt 2: Einmaliges Lesen *(IHK-relevanter Text, phänomenologisch aufbereitet)*

### 1. Klassen, Kapselung und Magische Methoden in Python
Statt Daten in losen globalen Variablen und getrennten Funktionen zu verstreuen, bündelt die **Objektorientierte Programmierung (OOP)** beides in **Objekten** (*Kapselung*). Eine **Klasse** (`class Book:`) ist der Bauplan; daraus erzeugte Objekte (`book1 = Book(...)`) sind **Instanzen** mit eigenen **Attributen** (Daten) und **Methoden** (Funktionen der Klasse).

Jede Methode erhält als ersten Parameter **`self`** – die automatische Referenz auf die aktuelle Instanz (beim Aufruf wird `self` nicht mitübergeben). Der Konstruktor heißt in Python **`__init__(self, ...)`** und legt Attribute über `self.title = title` an. Im Gegensatz zu Java gibt es in Python **keine harte Zugriffsbeschränkung** (`private`): Per Konvention markiert ein führender Unterstrich (`self._intern`) interne Details, die Nutzer nicht direkt anfassen sollen. Weitere **magische Methoden** steuern Standardverhalten: **`__str__()`** liefert eine lesbare Ausgabe für `print()`, **`__repr__()`** die eindeutige Entwickler-/Debug-Darstellung, und Methoden wie `__add__()` (`+`) oder `__eq__()` (`==`) überladen Operatoren für eigene Klassen.

### 2. Vererbung, flexible Funktionen, Type-Hints & Exceptions
Mit **Vererbung** (`class Ebook(Book):`) übernimmt eine Kindklasse alle Attribute und Methoden der Elternklasse und ergänzt nur die Unterschiede. Über **`super().__init__(...)`** ruft sie gezielt den Konstruktor oder überschriebene Methoden der Elternklasse auf (Python unterstützt sogar Mehrfachvererbung `class Kind(A, B):`).

Bei eigenen Funktionen (`def`) kannst du Standardwerte vergeben (*Keyword Arguments*, stets rechts von Pflicht-*Positional Arguments*), mit **`*args`** beliebig viele Positionsargumente als Tupel/Sequenz und mit **`**kwargs`** beliebig viele benannte Argumente als Dictionary einsammeln. Kurze anonyme Einzeiler-Funktionen schreibt man als **`lambda x: x ** 2`** – extrem praktisch als Sortierschlüssel: `sorted(people, key=lambda p: p[1])` gibt eine sortierte Kopie zurück, während `liste.sort()` direkt an Ort und Stelle sortiert. Optionale **Type-Hints** (`def double(val: int) -> int:`) dokumentieren erwartete Typen; **Achtung:** Python prüft Type-Hints zur Laufzeit *nicht* selbst – dafür nutzt man statische Checker wie **`mypy`**.

Zur Laufzeit abfangbare Fehler heißen **Exceptions**. Mit `try: ... except ZeroDivisionError: ...` verhinderst du harte Programmabbrüche; mehrere `except`-Blöcke fangen verschiedene Fehlertypen getrennt ab. Mit **`raise ValueError("...")`** löst du gezielt eigene Fehler aus (auch von `Exception`/`TypeError` abgeleitete eigene Fehlerklassen).

### 3. Module (`__main__`) und die Python-Standardbibliothek
Jede `.py`-Datei ist zugleich ein **Modul**, das du via `import modul`, `import modul as m` oder `from modul import Klasse` einbindest. Damit beim Importieren einer Datei nicht versehentlich deren Test- oder Hauptcode losläuft, umschließt man diesen immer mit **`if __name__ == "__main__":`** – denn nur bei direktem Start ist `__name__ == "__main__"`, beim Import enthält `__name__` den Modulnamen. Google-Docstrings (`"""..."""`) lassen sich direkt über `pydoc modulname` als Doku anzeigen.

Aus der **Standardbibliothek** solltest du fünf Kernmodule sicher beherrschen:
1. **`math`:** Mathematische Funktionen und Konstanten (`sqrt`, `log2`, `floor`, `ceil`, `gcd`, `lcm`, `pi`, `inf`).
2. **`sys`:** Schnittstelle zur Shell – `sys.argv` liefert Kommandozeilenargumente (`argv[0]` ist immer der Skriptname, `argv[1]` das erste echte Argument!).
3. **`os` / `os.path`:** Verzeichniszugriff (`listdir(".")`, `isfile()`, `isdir()`, rekursives `walk()`).
4. **`re`:** Reguläre Ausdrücke (`re.search(muster, text)` liefert ein Match-Objekt mit `.group()`/`.span()` oder `None`; `re.finditer()` iteriert über alle Treffer).
5. **`datetime`:** Zeitpunkte und Rechnen mit Zeitspannen – `datetime.now()`, Formatierung via `strftime("%d.%m.%Y")` sowie Addition/Subtraktion von Tagen/Wochen per **`timedelta(weeks=3, days=2)`**.
