## 📖 Schritt 2: Einmaliges Lesen *(Fokus-Wissen aus Kersken)*

### 1. Lineare Regression *(Kersken 10.3.1)*

Ziel: Eine stetige Zielgröße $y$ (z. B. Mietpreis) aus einem oder mehreren Features $x$ vorhersagen über eine Gerade bzw. Hyperebene:
$$h_\theta(x) = \theta_0 + \theta_1 \cdot x_1 + \dots + \theta_n \cdot x_n$$

* **Kostenfunktion *(Ordinary Least Squares / MSE)*:** Minimiert die Summe der **quadrierten Abstände** zwischen Vorhersage $h_\theta(x^{(i)})$ und echtem Wert $y^{(i)}$.
* **Optimierung:** Analytisch oder iterativ per **Gradientenabstieg** *(Gradient Descent)*.

```python
from sklearn.linear_model import LinearRegression

lr = LinearRegression()
lr.fit(x_train, y_train)          # Lernt Achsenabschnitt (lr.intercept_) & Steigung (lr.coef_)
vorhersage = lr.predict([[75]])   # Schätzt Preis für 75 m²
```

---

### 2. Logistische Regression *(Klassifikation, Kersken 10.3.2)*

Trotz des Namens „Regression“ ist die **Logistische Regression ein Klassifikationsverfahren**! Eine Gerade könnte Werte $< 0$ oder $> 1$ liefern – für Wahrscheinlichkeiten unbrauchbar.

* **Sigmoid-Funktion *(Logistische Funktion)*:** Presst jeden reellen Wert in das Intervall $(0, 1)$:
  $$\sigma(z) = \frac{1}{1 + e^{-z}}$$
* **Entscheidungsregel:** Ist $\sigma(z) \ge 0{,}5$ → Klasse `1`, sonst Klasse `0`.
* **Mehrklassen-Klassifikation *(z. B. 3 Iris-Spezies)*:** Prinzip **One-vs-All** (für jede Klasse ein eigener binärer Klassifikator; höchste Wahrscheinlichkeit gewinnt).

### 3. Der `scikit-learn`-Standardworkflow (`train_test_split`)

Um **Overfitting** aufzudecken, teilt man die Daten vor `fit()` sauber auf:

```python
from sklearn.model_selection import train_test_split
from sklearn.linear_model import LogisticRegression

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.33, random_state=42)
clf = LogisticRegression(max_iter=1000)
clf.fit(X_train, y_train)         # NUR auf Trainingsdaten lernen!
genauigkeit = clf.score(X_test, y_test)  # Bewertung auf ungesehenen Testdaten
```

## 🔺 Schritt 3: N – Nuklei & Pyramidenschema®

![[../../assets/LF10.08_Pyramide.svg]]

- **Spitze:** Lineare Regression sagt stetige Zahlen per Ausgleichsgerade voraus, Logistische Regression klassifiziert Wahrscheinlichkeiten (0..1) via Sigmoid.
- **Nukleus 1 (Lineare Regression):** Ziel: stetige Zahl (Mietpreis) h(x) = θ₀ + θ₁·x (Gerade) Minimiert quadrierte Fehler (OLS / Kostenfunktion J) sklearn: intercept_ (θ₀) und coef_ (θ₁..θₙ)
- **Nukleus 2 (Logistische Regression):** Trotz Name: KLASSIFIKATION! Sigmoid σ(z) = 1 / (1 + e⁻ᶻ) → Wert immer in (0, 1) Schwellenwert 0,5 → Klasse 0/1 >2 Klassen: One-vs-All (höchste Wahrscheinlichkeit siegt)
- **Nukleus 3 (sklearn-Pipeline):** train_test_split(test_size=0.33) fit(X_train, y_train): Training predict(X_neu): Vorhersage score(X_test, y_test): echte Generalisierung messen! max_iter bei Bedarf erhöhen

> [!tip] 💡 IHK-Prüfungstipp
> Klassische IHK-Fangfrage: 'Wofür wird Logistische Regression eingesetzt – Regression oder Klassifikation?' Antwort: **Klassifikation!** (Die Sigmoid-Funktion gibt Wahrscheinlichkeiten zwischen 0 und 1 aus.)
