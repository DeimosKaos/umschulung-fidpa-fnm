## Schritt 2: Einmaliges Lesen *(IHK-relevanter Text, phänomenologisch aufbereitet)*

### 1. Kundenschulung & Einweisung planen
Nach der Übergabe eines neuen Systems (vgl. Kersken `11.1.6` Übergangsphase: *„einweisen oder ausführlich schulen“*) entscheidet die Akzeptanz der Nutzer über den Projekterfolg:
- **Zielgruppenanalyse:** Vorwissen abfragen (Power-User vs. Einsteiger), Gruppen homogen halten.
- **Didaktik – Praxis vor Theorie (4-Stufen-Methode):**
  1. *Vorbereiten & Motivieren* (Nutzen für den Arbeitsalltag zeigen).
  2. *Vormachen & Erklären* (konkreter Workflow statt abstrakter Menüs).
  3. *Nachmachen lassen* (Üben in einer **Test-/Sandbox-Umgebung**, nie auf Produktivdaten!).
  4. *Üben & Sichern* (Kurzes **Handout / Spickzettel** mit Screenshots & FAQ mitgeben).
- **Wichtig:** Nicht zu viele Features auf einmal – typische Arbeitsabläufe (80 % des Alltags) stehen im Fokus.

### 2. Zweisprachige IT-Fachterminologie (Kersken Anhang B.1–B.2)
In IHK-Prüfungen und englischen Support-Queues begegnen dir regelmäßig diese Kernbegriffe aus Kerskens Wortliste:

| Englisch | Deutsch | Englisch | Deutsch |
| :--- | :--- | :--- | :--- |
| **operating system / kernel** | Betriebssystem / Systemkern | **buffer / cache** | Puffer / Zwischenspeicher |
| **internal / primary storage** | Arbeitsspeicher (RAM) | **coredump** | Hauptspeicherauszug |
| **packet switching** | Paketvermittlung | **interface / protocol** | Schnittstelle / Protokoll |
| **standard input / output** | Standardeingabe / -ausgabe | **queue / stack / overflow** | Warteschlange / Stapel / Überlauf |
| **concurrency / race condition** | Nebenläufigkeit / Wettkampfsituation | **batch processing** | Stapelverarbeitung |
| **business process / EPC** | Geschäftsprozess / EPK | **database / record / field** | Datenbank / Datensatz / Datenfeld |
| **design pattern / inheritance** | Entwurfsmuster / Vererbung | **outlier / standard deviation** | Ausreißer / Standardabweichung |

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Welches konkrete Problem löst **„Zweisprachige IT-Fachterminologie“** in der Praxis – und wo liegt dabei die typische IHK-Verwechslungsgefahr?*
### 3. Englische Support-Tickets & Fehlermeldungen meistern
1. **Schlüsselwörter isolieren:** *Permission denied*, *Connection timed out*, *Out of memory*, *Deprecated*, *Read-only file system*.
2. **Falsche Freunde vermeiden:** *actually* = tatsächlich (nicht aktuell!), *eventually* = schließlich (nicht eventuell!), *record* = Datensatz, *directory* = Verzeichnis.
3. **Kundenkommunikation:** Englische Fehlermeldungen für deutsche Endanwender immer **sinngemäß und lösungsorientiert** übersetzen statt Wort-für-Wort-Roboterdeutsch.
