## Schritt 2: Einmaliges Lesen *(IHK-relevanter Text, phänomenologisch aufbereitet)*

### 1. OOP: Kapselung, Vererbung & Interfaces (Kersken 7.2.3)
- **Klasse & Objekt:** Bauplan vs. konkrete Instanz (`new Artikel(...)` ruft den **Konstruktor** auf). Mit `this` referenziert ein Objekt sich selbst.
- **Kapselung (*Information Hiding*):** Attribute werden **`private`** geschützt; Zugriff erfolgt kontrolliert über **`public` Getter/Setter** (mit Validierung!).
- **Vererbung (`extends`) & Polymorphie:** Eine Unterklasse erbt Attribute/Methoden einer Oberklasse (*Java erlaubt nur **Einfachvererbung** bei Klassen!*), ruft mit `super(...)` den Eltern-Konstruktor auf und überschreibt Methoden (`@Override`).
- **`abstract class` vs. `interface`:** Eine *abstrakte Klasse* kann bereits fertige Methoden + Attribute enthalten (`extends`, max. 1 Oberklasse). Ein **`interface`** definiert primär Methodensignaturen als Vertrag – eine Klasse kann **beliebig viele Interfaces** gleichzeitig implementieren (`implements SearchInfo, Serializable`).

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Warum erlaubt Java bei Klassen nur **eine** Oberklasse (`extends`), bei Interfaces aber **mehrere** (`implements`)?*

### 2. Exceptions, Collections & Pakete (Kersken 7.2.4)
- **Exceptions:** Statt kryptischer Fehlercodes wirft Java Ausnahmeobjekte (`throw new IllegalArgumentException(...)`). Abfangen mit `try { ... } catch (SQLException e) { ... } finally { ... }` (`finally` läuft *immer* – ideal zum Schließen von Dateien/DB!). *Checked Exceptions* (z. B. `IOException`) **müssen** behandelt oder per `throws` weitergeleitet werden.
- **Collections mit Generics:** Statt starrer Arrays nutzt man `ArrayList<String>` (dynamische Liste) und `HashMap<String, Integer>` (Schlüssel-Wert-Zuordnung).
- **Packages & `static`:** `package com.firma.app;` ordnet Klassen im Namensraum. `static`-Methoden gehören zur Klasse selbst (aufrufbar ohne `new`, z. B. `Math.random()`).

> [!question] ⏸️ Denkstopp (10 Sek.)
> *Welchen praktischen Vorteil hat eine `ArrayList<Double>` gegenüber einem klassischen `double[]`-Array?*

### 3. Build-Management mit Apache Maven (Kersken 9.4.3)
Bei größeren Java-Projekten lädt niemand mehr `.jar`-Bibliotheken manuell herunter. **Maven** standardisiert die Ordnerstruktur (`src/main/java`, `src/test/java`) und verwaltet in **`pom.xml`** alle externen **Dependencies** (z. B. `junit`, `mysql-connector-java`) per `groupId`, `artifactId` und `version`. Zentrale Befehle: `mvn compile`, **`mvn test`** (führt JUnit-Tests aus) und `mvn package` (baut `.jar`).
